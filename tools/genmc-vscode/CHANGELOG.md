# Changelog

## Versioning

We follow **SemVer** (`MAJOR.MINOR.PATCH`) and keep entries in a **Keep a Changelog**-style format.

- `MAJOR`: breaking changes (for `0.y.z`, breaking changes may also land in `MINOR`)
- `MINOR`: new features (non-breaking)
- `PATCH`: bugfixes / small improvements

Keep `tools/genmc-vscode/package.json` `version` in sync with the latest released entry below.
