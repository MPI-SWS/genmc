# GenMC VS Code Extension — Developer Quickstart

## Repo layout (extension)

- `package.json`: extension manifest (commands + settings) and npm scripts.
- `src/extension.ts`: registers the commands and runs `genmc` on the active file.
- `src/test/extension.test.ts`: extension tests (runs under the VS Code test host).
- `out/`: compiled JS output (generated by `npm run compile`).

## Prerequisites

- Node.js + npm (project scripts use `npm`).
- VS Code (for debugging via the Extension Development Host).

## Install + build

From `tools/genmc-vscode/`:

```bash
npm ci
npm run compile
```

## Run / debug in VS Code

- Open the `genmc-tool/` repository in VS Code.
- In **Run and Debug**, select `Run GenMC VS Code Extension`.
- Press `F5` to launch an **Extension Development Host**.
- In the dev host, open a file and run:
  - `GenMC: Run on Active File`
  - `GenMC: Configure`

The extension writes output to the **GenMC** output channel.

## Run tests

You can run tests in either of these ways:

- In **Run and Debug**, select `Test GenMC VS Code Extension` and press `F5`.
- In VS Code, run the `genmc-vscode: npm test` task.
- From `tools/genmc-vscode/`, run:

```bash
npm test
```

Notes:

- Tests live in `src/test/**/*.test.ts` and are compiled to `out/test/**/*.test.js`.
- `npm test` uses the VS Code test runner (see `package.json`).

## Lint

```bash
npm run lint
```
